🗣️ ask core command
uv run python -m sales_agent.cli ask "Which stores did the best in 2021?"

Type a question in plain English. The agent works out which tools to use, runs them in order, and prints a human-readable answer. Every step is silently recorded in Phoenix.

📝 Your question
→
🤖 Router (OpenAI)
→
🔍 lookup_sales_data
→
🗃️ SQL → DuckDB
→
🧠 analyze_sales_data
→
💬 Final answer
Example
IN "Which stores did the best in 2021?"
→ SQL: SELECT store_id, SUM(sales) … ORDER BY 2 DESC LIMIT 5
→ DuckDB returns a table of numbers
→ LLM reads the table, writes English
OUT "Store 2970 had the highest sales at 84,454…"
🏆 eval quality check
uv run python -m sales_agent.cli eval

Run after ask. Reads every trace Phoenix recorded and scores it across 4 dimensions. Scores are written back to Phoenix so you can see them in the UI.

🔧 tool-calling
Did the router pick the right tool with the right arguments?
🗄️ sql
Is the generated SQL valid and actually correct?
💬 clarity
Is the final answer clear and easy to understand?
🖼️ code
Does the generated chart code run without errors?
Example output
tool-calling
3/3 ✓
sql
2/3
clarity
3/3 ✓
code
0/0

🧪 experiment robustness test
uv run python -m sales_agent.cli experiment

Asks the agent the same question 17 different ways. Measures whether it takes the same number of steps each time. Fewer steps = more direct = better score.

17 phrasings
→
run agent on each
→
count steps per run
→
score = optimal ÷ actual
Scoring example (optimal = 5 steps)
"avg qty per txn?"
1.00
"avg qty per sale?"
1.00
"mean items/purchase?"
0.71
0.71 = 5 optimal ÷ 7 actual steps — wasted 2 steps on this phrasing
📦 generate_data.py dataset tool
uv run python scripts/generate_data.py uv run python scripts/generate_data.py --until 2025-12-31 --seed 7

Extends the sales dataset. The data file has 1.48M rows. This script appends new rows for any missing dates. Safe to run many times — never duplicates rows.

read parquet
→
find last date
→
generate new rows
→
append to file
--until 2025-12-31
Stop generating at this date. Default is today. Use when you want a fixed snapshot.
--seed 7
Pins the randomness. Same seed = identical rows every time. Share the seed and anyone can reproduce your exact dataset.
seed 7 → row A seed 7 → row A ✓ seed 42 → row B ≠
Example
Data ends at: 2025-06-01 · Today: 2026-09-04
→ appends 2025-06-02 → 2026-09-04 · dataset grows to ~1.6M rows
